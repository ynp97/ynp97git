# G. ynp97 TODOインボックス

### G. ynp97 TODOインボックス

- 本体: [[ynp97 TODOインボックス.html]]
- Macアプリ: `/Applications/TODOインボックス.app`
- SwiftPM本体: `アプリ本体/ynp97-todo-inbox`
- ビルドスクリプト: `アプリ本体/ynp97-todo-inbox/script/build_and_run.sh`
- アイコン生成: `アプリ本体/ynp97-todo-inbox/script/make_icon.swift`
- 保存サーバー: `アプリ/ynp97_todo_server.py`
- 種別: Obsidian連携TODO Inbox / 戦略モード相談補助
- localStorage key: `ynp97_todo_inbox_simple_v1`
- 状態: v0.4。Dockに置いて使うためのSwiftUI Macアプリ版を作成し、`/Applications/TODOインボックス.app` にインストール済み。黄色地に太いTのアプリアイコンはユーザー確認済みで正式採用。HTML版も試作用として残す。

目的:
- 「やらなきゃ」と思ったことを気軽にどんどん入れる受け皿にする。
- Obsidian連携は画面の主役にせず、バックグラウンドで `TODOインボックス.md` へ保存する。Macアプリ版のJSON本体は `~/Library/Application Support/ynp97 TODOインボックス/todo-data.json`。
- 新しいAI相談では、`ynp97` の後に貼れる相談パックを生成し、TODOから今日の主成果物を絞れるようにする。
- 並んだTODOに「今日中」「今週中」「急ぎ」「待機」などの付箋タグを貼る。付箋タグはユーザーが自由に追加できる。

実装済みの主な機能:
- TODOの追加、完了、削除
- 期限日入力と期限表示
- 期限付きTODOのカレンダー追加（EventKit。初回はmacOSの許可が必要）
- TODO選択と付箋タグの貼り付け/取り外し
- 初期付箋: 今日中 / 今週中 / 急ぎ / 待機
- ユーザー定義付箋の追加
- 全部 / 未完了 / 完了の表示切り替え
- 検索
- 現在地TODOの初期投入
- Obsidian用Markdownの自動生成とローカル保存
- `ynp97` 相談パック生成、コピー
- JSONデータのバックグラウンド保存
- SwiftUIアプリバンドル化、`/Applications` へインストール
- 黄色地に太いTの `.icns` アイコン生成とバンドル反映

現在の課題:
- 実際に使って、付箋タグの貼り方が直感的か確認する。
- カレンダー追加の初回許可と実際の登録先カレンダーを確認する。
- Wordに書き散らかしたTODOをAIで整理する機能は、いったん表から下げた。必要なら別画面または折りたたみで戻す。
- `俺は世界を変える！` 本体アプリと統合するか、このInboxを手前の受け皿として独立させるか判断する。

次に見ること:
- `/Applications/TODOインボックス.app` をDockに残し、思いついたら開いて入力する。
- TODOを数件追加し、左の付箋を貼って、`TODOインボックス.md` に自動保存されるか確認する。
- 期限付きTODOを1つ作り、カレンダーに追加して許可フローを確認する。
- 付箋名を追加し、実際の運用に必要なタグを残す。
- Word整理機能を戻すなら、メイン画面ではなく「AIで整理」だけに畳む。
