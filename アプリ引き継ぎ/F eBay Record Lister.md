# F. eBay Record Lister

### F. eBay Record Lister

- 関連メモ: [[e-bay・ヤフオクツール]]
- 種別: レコード用eBay出品管理Webアプリ
- Git管理コピー: `アプリ本体/eBay-Record-Lister`
- 開くもの: `アプリ本体/eBay-Record-Lister/index.html`
- 主なファイル: `index.html`, `styles.css`, `app.js`
- localStorage key: `ebay-record-lister-v1` / 送料表: `ebay-record-lister-shipping-rates-v1`
- 状態: v0.4相当。レコード商品登録、Discogs取込、写真バーコード検出、送料別/送料無料に対応した価格計算、英語出品文生成、eBay出品コピペパック、確認リンク、CSV/JSON出力までのローカルHTML試作あり。
- 2026-07-06 出品シミュレーター化（重要）: 本人方針「出品部分を第一に。送料の計算・表記と利益計算をシンプルに」。編集画面の最上部に**出品シミュレーター**を新設。①送料自動計算=重さ(g)×発送方法×送り先で送料表から自動算出（手動切替可・重量超過警告）②**損益分岐点**（これ未満は赤字、USD/円表示）③目標利益を出すおすすめ価格 ④今の価格での利益・利益率（赤字は赤表示）⑤商品価格USD⇔円の為替連動 を実装。送料表は日本郵便公式（2026-07時点）の小形包装物(航空)を**アメリカ=第4地帯(100g830円+210円/100g)、ヨーロッパ・カナダ・オセアニア=第3地帯(100g510円+180円/100g)** でプリセット。表は画面内で編集・行追加・貼り付け一括取込（「発送方法 送り先 上限g 円」形式、桁区切りカンマ対応）・JSONバックアップに含む。**自動読取（サイトスクレイピング）は安定性優先で不採用**（本人合意）。既存データはshipCostMode=手動扱いで従来挙動を保持。単体テストで公式料金一致・損益分岐で利益≒0・パースを確認。node構文チェック済み。
- ⚠️ 2026-07時点の実務注意: 日本郵便の**アメリカ宛は2026-04-14から関税事前支払い（Zonos Prepayアプリ・指定郵便局）が必要**（2025年の米デミニミス廃止の影響）。米国宛はeLogi(FedEx/DHL)やeBay International Shippingの方が実務的な場合が多い。米国宛送料表を使う際はこの前提を確認する。
- 2026-07-06 損益分岐の両建て表示: シミュレーターの損益分岐を「送料別」「送料無料」の2箱で常時併記（切替不要で比較可能、現在の設定側に「今の設定」印）。送料無料分岐＝(仕入+梱包+送料)/(1-手数料率)。単体テスト済み。
- 2026-07-06 コンディション定型文チップ追加: 検品メモ欄の上に、eBayレコード出品で定番の英語状態表記（Goldmine系: play-tested / ring wear / seam split / surface noise / OBI included 等15種、日本語ラベル付き）をチップ表示。クリックで選択すると `item.conditionTags` に入り、英語説明文とConditionコピペパックに `- ` 行として自動反映。「定型文を編集」から追加・削除可能（英語表記は必須・日本語ラベル省略可）。保存は `ebay-record-lister-condition-phrases-v1`、JSONバックアップ/復元に含む。単体テストでタグ反映・タグなし時の後方互換を確認。既知の小課題: OBI/Insertの値が「あり/なし」のまま英文に入る（従来からの挙動・未修正）。
- 2026-07-06 Dockランチャー追加: `/Applications/eBay Lister.app`（緑地#007c74に白の小文字e、`AppIcon.icns` は Vault内に生成済み）。作成は `アプリ本体/eBay-Record-Lister/セットアップ_Dock追加.command` をダブルクリック（Gatekeeperで開かない時は右クリック→開く）。多重起動防止は二層: ①ランチャーがAppleScriptで既存の「eBay Record Lister」ウインドウを検出したら手前に出すだけで新規起動しない（初回にChrome操作の許可が必要）②app.js側にlocalStorageハートビートの起動時ブロッカー（後から開いた画面に「既に開いています」オーバーレイ、閉じる/強行の二択）。Chrome起動は `--profile-directory=Default` ＋ `?app=1` 固定で保存分岐を防止。Dock重複追加はエンコード形式込みでチェック済み。

> [!important] 送料・関税・チャネル選び・価格の決め方は **[[💴 物販・オークション引き継ぎ（AI共通）]]**（合図 `auc97`）が正本

目的:
- まずEP/LPレコードをeBayへ出品するための商品情報を整理する。
- 盤質、ジャケット状態、帯、インサート、型番、写真フォルダ、価格根拠を一箇所に集める。
- API連携前に、自分用の出品フローが続くかを確認する。

実装済みの主な機能:
- 商品の登録、編集、複製、削除
- ステータス管理: 未出品 / 下書き / 出品済み / 売却済み / 発送済み
- 盤質、ジャケット、帯、インサート、レーベル、型番、重量の入力
- Discogs Release URL / ID からアーティスト、タイトル、レーベル、型番、国、年、ジャンル等を取り込み
- 写真ファイルからバーコード検出、ファイル名/OCRテキストから型番・年・盤種等を推定
- 仕入れ、海外送料、梱包、手数料、為替、目標利益から商品価格と購入者総額を計算
- 送料別/送料無料の切替。送料別では eBay の Price 欄に入れる商品価格と、購入者総額（商品価格＋送料）を分けて表示
- 英語タイトルと説明文の下書き生成
- eBay画面に貼るための出品コピペパック生成（Title / Price-SKU / Item specifics / Condition / Description / Shipping-Returns / 一括コピー）
- eBay sold / active、Discogs、Popsike、Yahoo Auctionsの確認リンク生成
- CSV出力
- JSONバックアップ、復元

現在の課題:
- CSV列はまだ汎用の下書きで、eBayの実テンプレートに完全対応していない。
- 写真の本格OCRは未実装。現状はブラウザのバーコード検出、ファイル名、貼り付けOCRテキストからの推定。
- 保存はブラウザ内localStorageのため、長期運用ではJSONバックアップが必要。

次に見ること:
- 実際のEPレコードを3枚登録して、入力項目の過不足を確認する。
- まず3F=C「とまどい」で出品コピペパックを作り、eBayの出品画面に貼って不足項目を確認する。
- eBayの出品CSVテンプレートに合わせて列を調整する。
- 写真チェックリスト、検品チェックリスト、sold/completed相場メモを追加する。
- ヤフオク向けタイトル・説明文にも出力できるようにする。
