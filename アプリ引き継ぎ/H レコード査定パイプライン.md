# H. レコード査定パイプライン

### H. レコード査定パイプライン（record_lister.py / Qwen3-VL→Discogs）

- 実体: `アプリ/レコード査定/record_lister.py`（220行）
- 手順書: `アプリ/レコード査定/セットアップ手順.md`
- 関連: [[レコード査定シート（サンプル22枚）]] / [[e-bay・ヤフオクツール]] / 上の F. eBay Record Lister
- 種別: 写真→ローカルVLM→Discogs照合→査定表(MD/CSV/JSON) の自動パイプライン（CLIツール）
- 状態: **2026-06-23作成済み・未台帳だった**。本体は動く構成。Qwen3-VL未ダウンロードのため実走はこれから。

目的:
- 写真フォルダを読み、型番・アーティスト・タイトル・バーコード等を抽出し、Discogsで版・再発・相場(lowest_price/num_for_sale)・URLを引いて査定表を自動生成する。

構成:
- VLMバックエンド: **LM Studio**(`localhost:1234`, 既定) または **Ollama**(`localhost:11434`)。推奨モデルは手順書どおり **Qwen3-VL 30B-A3B 4bit/MLX**（軽ければ8B）。※ユーザーが今ダウンロード中のモデルはこれ。
- 画像はMac上で完結。Discogs照合ONの時だけ型番等のテキストをDiscogsへ送る。
- 出力: 写真フォルダ隣の `_査定結果/` に `査定シート_qwen.md` / `.csv` / `results.json`。

実装済みの主な機能:
- 写真の縮小読み込み(PIL)・VLMへのJSON強制プロンプト（推測で埋めない指示つき）
- Discogs: バーコード検索→無ければ型番/アーティスト検索、master versions（再発）、marketplace/stats（最安値・出品数）
- MD/CSV/JSON出力、レート制限の自動ウェイト

残課題 / 次に見ること:
- Qwen3-VL（30B-A3B 4bit MLX）をLM Studioで起動して**22枚で実走**＝型番が読めた率・Discogs命中率を実測（このセッションの保留事項）。
- sold中央値はDiscogs APIに無い（marketplace/statsは最安値・出品数のみ）。**Have/Want と sold中央値はリリースページ側**にあるので、候補フラグ用に取得方法を足す。
- F(eBay Lister)へCSVを流す連携。eBay sold/ヤフオク/Popsikeの実勢検証リンク生成（F側の残課題と共通）。

注意:
- これはトリアージのたたき台。相場・再発・最終出品判断は本人確認前提。
- **未台帳だったため今朝の物販相談で見落とされ、機能が一部再実装された。今後はレコード物販の相談時、必ずF・Hの両実体を先に開く。**
