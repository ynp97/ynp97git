# AB パスワード帳

## 何のためのアプリか

Googleパスワードマネージャーに、打ち間違えたパスワードや覚えのない自動生成パスワードが混ざり、手書きの控えしか信用できなくなっていた（2026-09-25 本人）。
**実際にログインが通ったものだけを「正解」として扱い、少しずつ整える**ための管理画面。

## 決まったこと（2026-09-25）

1. Googleパスワードマネージャーは並行して使い続ける。うまく行ったら自作に全移行する。
2. 保存形式は KeePass（.kdbx）。自作アプリが止まっても KeePassXC（Mac）／Strongbox（iPhone）で同じファイルを開ける。
3. Googleの登録分と手書きの控えを **全部「未確認」で取り込み**、使うときに一件ずつ整える。
4. 分類は2軸。**状態**（確認済み／未確認／要再設定／廃止）と**分野**（学校・物販・教会・牧師会・POP・制作・発信・個人・家庭・共通基盤）。分野は確認済みにするときに決める。
5. 状態は「ログインできた」ボタンでしか確認済みにならない。パスワードを書き換えると自動で未確認に戻る。
6. Chromeでの自動入力・iPhoneでの自動入力は自作しない。必要になったら KeePassXC-Browser／Strongbox で同じファイルを使う。

## 実体

- 本体: `~/Desktop/AI関係/パスワード帳/パスワード帳.html`（HTML1枚。Chromeで開く。インストール不要）
- ソース: `~/Desktop/AI関係/パスワード帳/src/`（`src.html` を直して `build.py` で本体を作り直す。手順は同フォルダの README）
- 使っている部品: kdbxweb 2.1.1（.kdbx の読み書き）、hash-wasm（Argon2）。暗号は自作していない。
- 保存ファイル（.kdbx）の置き場所は本人が「新しく作る」で決める。**このアプリのフォルダとは別物。**
- 2026-09-25 本物の保存ファイルは **iCloud Drive/パスワード帳/パスワード帳.kdbx** に置いた（書類フォルダから移動）。**Vaultの中には置かない**（VaultはGitHubと同期しているため）。

## 保存の中身（KeePassXCで開いたときの見え方）

- 状態 → タグ（`確認済み`/`未確認`/`要再設定`/`廃止`）
- 出どころ → タグ（`Google`/`手書き`）
- 最後にログインを確かめた日 → カスタム項目 `確認日`
- 状態の変わり方 → カスタム項目 `状態の履歴`（日付つきで追記）
- 分野 → グループ。取り込み直後は `未分類（取り込み）`
- KDBX4 / Argon2d 64MiB（KeePassXC既定と同じ）

## 仕組みで守っていること

- ページは外部へ一切通信できない（Content-Security-Policy）。パスワードが外へ出ない。
- 保存の前に、書く中身を同じマスターパスワードで開き直して、開けたときだけ上書きする。
- 10分操作がないと自動で閉じる。コピーしたパスワードは30秒後にクリップボードから消す（Chromeが前面にあるとき）。
- 同じサイトの候補が複数あるときは「同じサイト N件」と出る。1件を確認済みにすると、ほかを「廃止」にする（削除はしない）。

## 動作確認の記録

- 2026-09-25 作業環境のChrome（Playwright）でダミーデータ: 新規作成→Google CSV取り込み（引用符・カンマ入りの行を含む）→手書き追加→確認済み（分野選択必須・別候補の廃止）→要再設定→廃止→確認済みのパスワード書き換えで未確認に戻る→閉じて開き直し（違うパスワードは拒否）。すべて通った。
- 同じファイルを **keepassxc-cli 2.7.6** と pykeepass で開き、グループ・タグ・確認日・パスワードが一致することを確認。逆に KeePassXC で足したエントリをこのアプリで開けることも確認（タグのないものは未確認として出る）。
- **未確認**: 本人のMacのChromeで、ファイルの上書き保存（File System Access API を file:// から使う）が効くか。作業環境では保存先を模擬した。

## ★踏んではいけない地雷

- kdbxweb はタグを「, 」区切りで書く。pykeepass が前に空白の付いたタグとして読んだため、「;」区切りに上書きしている（src.html 冒頭）。**この上書きを消さない。**
- 動作確認用の `window.__pw` は `build.py --release` で外している。**配布物を `--release` なしで作らない。**
- Google から書き出した CSV はパスワードが暗号化されずに入っている。取り込んだらすぐ消す（アプリも取り込み後にそう表示する）。
