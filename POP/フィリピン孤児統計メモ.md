# フィリピン孤児統計メモ

POP、孤児院訪問、将来の説明資料で使うための参照メモ。数字は定義によって大きく変わるので、必ず定義とセットで使う。

## 結論

2022年のDHS調査では、フィリピンの18歳未満の子どものうち、**母・父・または両方を亡くした子は6.1%**。UN WPP 2024の年齢別人口で、2022年のフィリピン18歳未満人口は約**4,012万人**なので、人数にすると約**245万人**。

ただし、これは「両親とも亡くした子」だけではなく、**片親を亡くした子も含む広い意味の孤児**。

より狭く、**両親とも亡くしていて、実の親と暮らしていない子**はDHSで**0.3%**。人数にすると約**12万人**。

POPの文脈で特に重要なのは、**実の父母どちらとも暮らしていない子が11.0%**いること。人数にすると約**441万人**。これは両親が生きていても、親族に預けられている子、親と離れている子などを含む。

## 数字の整理

| 定義 | 割合 | 2022年18歳未満人口からの概算 |
| --- | ---: | ---: |
| 母・父・または両方を亡くした子 | 6.1% | 約245万人 |
| 実の父母どちらとも暮らしていない子 | 11.0% | 約441万人 |
| 両親とも亡くし、実の親と暮らしていない子 | 0.3% | 約12万人 |
| 両親は生きているが、実の親と暮らしていない子 | 9.1% | 約365万人 |

## 説明に使いやすい表現

> フィリピンでは、片親または両親を亡くした18歳未満の子どもが約245万人規模いる。さらに、実の親と暮らしていない子どもは400万人を超えると見られる。

> POPが向き合う現実は、孤児院の中だけではない。親の保護から離れた子ども、親族や地域に支えられている子ども、教育や仕事の機会からこぼれそうな子どもたちまで含む広い現実である。

## 注意点

- 「孤児院にいる人数」は、この約245万人や約441万人とは別。多くの子は親族、地域、施設、支援団体の中に散らばっている。
- 「孤児」という言葉は、国際統計では片親を亡くした子も含むことがある。日本語で説明するときは誤解を避けるため、必ず「片親または両親を亡くした」と補う。
- POPの資料では、煽る数字としてではなく、支援対象の広がりを理解するための背景数字として使う。

## 孤児院訪問で聞くとよい質問

- この施設の子どもは何人か。
- 両親を亡くした子、親がいるが養育できない子、捨てられた子の割合はどれくらいか。
- 学校に通えているか。
- 卒業後や18歳以降の支援はあるか。
- いま一番足りないものは何か。

## 計算メモ

- UN WPP 2024の `WPP2024_PopulationBySingleAgeSex_Medium_1950-2023.csv.gz` から、Location=Philippines、Time=2022、AgeGrpStart=0〜17を合計。
- 2022年18歳未満人口: 40,121.164千人 = 約40,121,164人。
- 6.1% = 約2,447,391人。
- 11.0% = 約4,413,328人。
- 0.3% = 約120,363人。
- 9.1% = 約3,651,026人。
