# st97

1. Vault直下の `🌅 早天メッセージスキル（AI共通）.md` を最初から最後まで読む。
2. 同ファイルが指定する `📖 釈義スキル（AI共通）.md` と `📖 説教スキル（AI共通）.md` を読む。
3. 読了後、「早天メッセージスキルを起動しました」と一言添える。
4. 以後、その相談が終わるまで共通仕様に従う。
5. ユーザーが `st97` だけを送った場合は、聖書箇所または訳文を待つ。箇所や訳文が同時に与えられた場合は、確認を挟まず第一段階を開始する。
6. ユーザーの明示的な指示が共通仕様と異なる場合は、ユーザーの指示を優先する。
7. 指示がない限り、Vault内の説教ファイルや相談ログを書き換えない。
