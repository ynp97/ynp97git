```sh

python3 server.py
```

ブラウザで `http://127.0.0.1:8797` が開きます。

## 更新

- 普段: `カードデータを更新.command` をダブルクリック（新しい詳細の取得後、種別とタイプを公式絞り込み結果で照合）
- AIから詳細だけ更新: `python3 update_cards.py`（新しいカードだけ）
- 前回の失敗も再試行: `python3 update_cards.py --retry-errors`
- 全カードの変更確認: `python3 update_cards.py --refresh-all`
- 動作確認用に10枚だけ: `python3 update_cards.py --limit 10`

## AIから呼び出す

`poke97` はウェブページを大量に読まず、`search_cards.py` でこのDBを全件検索します。

```sh
python3 search_cards.py '相手のベンチ ダメカン' --category ポケモン
python3 search_cards.py --stage たね --type electric --ability yes --hp-max 100
python3 search_cards.py --subcategory スタジアム
python3 search_cards.py 'メガシンカexがきぜつしたとき、相手はサイドを3枚とる' --damage-min 240
python3 search_cards.py 'ふしぎなアメ' --versions   # 版（セット・番号）も並べる
python3 search_cards.py --ability-text '【水】 エネルギー' --category ポケモン  # 特性の文だけを検索
python3 search_cards.py --attack-text 'ベンチ' --attack-energy water           # ワザの文・コストで検索
```

## AIへの質問窓

画面のいちばん上で、日本語のまま聞けます。例:「水エネルギーを特性で持ってこれるポケモンをあげて」

事実の出どころは常にこのローカルDBです。AIがするのは2つだけ。

1. 質問を検索条件へ翻訳する（取りこぼさないよう、ゆるめに）
2. DBが返した候補**だけ**を読んで、合うものを選び理由を書く

**候補に無いカード名をAIが書いたら `※` 印をつけて出します。** 記憶から補われたカードが混ざるのを見えるようにするためです。印がついた名前は無いものとして扱ってください。

- 接続先はOpenAI互換なら何でも。既定は **LM Studio**（`http://127.0.0.1:1234/v1`・無料・端末外へ出ない）。LM StudioのLocal Serverを起動しておきます。
- 外部APIにする場合は画面の「接続先の設定」で base_url とキーを変更（`data/ai_config.json` に保存。画面には返しません）。
- AIが動かないときは、下の検索欄の条件で候補を集め、**貼り付け用のテキスト**を出します。Claude等へ貼れば同じことができます。

```sh
python3 ai_ask.py '水エネルギーを特性で持ってこれるポケモン'
python3 ai_ask.py 'ゲッコウガ' --packet-only   # AIを呼ばず、貼り付け用テキストだけ
```

## 本文中のエネルギー記号（2026-08-07）

公式ページは、本文中のエネルギーとタイプを**文字ではなくアイコン**で書いています。以前の解析はそれを消していたため、DBの本文が次のようになっていました。

- 「基本【水】エネルギーを1枚」→「基本エネルギーを1枚」（何色か消える）
- 「自分の【鋼】または【超】ポケモンに」→「自分のまたはポケモンに」（文が壊れる）

解析を直し、`【水】` の形で残すようにしました。**一度だけ全カードの本文を取り直す必要があります。**

`本文を取り直す（エネルギー記号）.command` をダブルクリック（先に10枚で確かめてから、全件30〜50分）。

取り直す前は、画面の上に黄色い帯が出ます。**検索するときは「水エネルギー」ではなく `【水】 エネルギー` と書きます。**

## 検索結果は「版」ではなく「カード」

公式のスタンダード一覧には、同じカードの別絵レア・デッキやプロモの再録・文言だけ違う旧版が並びます。5,550枚は**2,054種**です。検索結果は種類ごとに1件だけ出し、残りは「他◯版」に畳みます。

- ポケモン: 名前とHP・タイプ・進化・弱点・抵抗力・にげる・特性・ワザ・本文が全部同じなら同じカード。同名でも効果が違えば別カードのままです（ニャオハ、シェイミなど）。
- トレーナーズ・エネルギー: 同名同種別なら同じカード。旧版が今も使えるのは効果が同じだからで、差は文言と空白だけです（ふしぎなアメ83版、ポケモンいれかえ162版）。
- 代表に出すのは、一番新しい通常枠（番号 ≤ 分母）。プロモ、別枠レアの順に下げます。
- **DBからは1枚も消していません。** 全版が `cardID` 単位で残り、`--versions` と画面の「他◯版」から引けます。販売側で版ごとの相場を見るときはここを使います。

## 範囲と限界

- 一覧件数と保存件数が違えば更新を失敗扱いにします。
- `--damage-min` は、印刷ダメージが足りなくても `×` `＋` のついたワザを落とさず「要計算」として残します。印刷ダメージだけで切ると、条件しだいで届くワザを見落とします。確定するものだけ見たいときは `--damage-certain`。
- ダメージ計算には、弱点・抵抗力・与える側の増減・受ける側の効果も入ります。検索結果はあくまで候補です。
- 「ダメカンをのせる」「きぜつさせる」はワザのダメージではありません。
- 公式検索の内部JSONは公開保証APIではありません。変更時は `card_db.py` の取得部を直します。
- 2026-08-07最終確認: 現行スタンダード5,550 / 5,550枚＝2,054種、取得失敗0。ポケモン3,305、トレーナーズ1,591、エネルギー654。
