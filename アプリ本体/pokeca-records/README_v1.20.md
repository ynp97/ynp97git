# ポケカ戦績 v1.20

v1.19の画面・集計・バックアップをそのまま保ち、**日時スタンプの取り方だけ**を直した。

## 直した中身

### 1. 保存を押した瞬間の時刻を記録するようにした（本体の不具合）

v1.19までは、入力画面の日時が**入力画面を開いた瞬間**（＝直前の保存が終わった瞬間）で止まっていた。
対戦を終えてから入力しても、記録されるのは「1つ前の入力を終えた時刻」だった。
実データでも、まとめて入力した戦績が30〜60秒間隔で並ぶ形で出ていた。

v1.20では、日時欄に**手で触っていない限り**、保存ボタンを押したその瞬間の時刻を書き込む。
日時欄の表示も5秒ごとに現在時刻へ追従するので、画面に出ている時刻と保存される時刻が一致する。

### 2. 日時を手で直したときは、その値をそのまま使う

日時ピッカーを自分で動かすと自動追従は止まり、欄の下に「手で指定した日時で記録します」と出る。
横の「今にする」を押せば自動追従に戻る。
（上部にあった「今日・現在時刻」ボタンは、この「今にする」に統合して削除した。）

戦績を**編集**するときは、保存済みの日時をそのまま保持する（勝手に今の時刻へ書き換えない）。

### 3. 未来の日時を保存できないようにした

2分以上先の日時のまま保存しようとすると、保存せずに警告を出す。
v1.19までのデータには、年が1つ進んで `2027-09-02` になった戦績が1件混ざっていた。
この種の入力ミスを次から止める。

### 4. 日時が読めない戦績を「今の時刻」に化けさせないようにした

v1.19までは、SQLiteの日時文字列が想定形式（小数秒つき）でないと、
その戦績は黙って**アプリを開いた時刻**に置き換わっていた。エラーも出なかった。

v1.20では、小数秒なしのISO形式も読めるようにしたうえで、
それでも読めない場合は今の時刻に化けさせず、一覧のいちばん古い側に寄せて件数を警告表示する。

## 変えていないもの

画面構成、集計、相性表、デッキ管理、レート欄、自動バックアップ（Mac内＋iCloud）、
JSON/CSV入出力、SQLiteのスキーマは v1.19 のまま。データベースはそのまま引き継げる。

## ロールバック

`PokecaRecords_v1.19.app` は残してある。問題が出たらそちらを起動すればよい。
