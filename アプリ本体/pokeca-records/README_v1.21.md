# ポケカ戦績 v1.21

v1.20の記録内容・集計・バックアップ・SQLiteスキーマはそのまま。**入力画面の操作性だけ**を変えた。

## 変えたこと

### 1. 大会をボタン式にした

`PTCGL午前` `PTCGL午後` `PTCGL夜` `ジムバトル` `1人回し` の5つをボタンで選ぶ。
テキスト入力・候補メニュー・「左端に固定」は大会欄から外した（デッキ欄には従来どおり残っている）。

表記は**既存207件のデータに合わせている**。「午前中」「一人回し」にすると集計上、別の大会として分かれてしまうため。
選択中のボタンをもう一度押すと未選択に戻る。
過去の戦績を編集したとき、その戦績の大会名が5つに無ければ、その名前のボタンが右端に足される（値が消えない）。

### 2. 保存ボタンを大きくして、レート〜初手の右へ移した

`レート / 勝敗 / 先・後 / 初手` の4行の右隣に、160×104の大きな保存ボタンを置いた。
色（勝ち＝緑／負け＝赤）、Returnキーで保存、編集中は「更新する」に変わる点は従来のまま。
「編集をキャンセル」は保存ボタンの下に移した。

### 3. 自分のデッキ・レート・大会は前回入力が残る

連続して入力するとき、この3つは同じことが多いため、保存後もそのまま残す。
アプリを終了しても次回起動時に復元する（`UserDefaults`の`carry_myDeck` / `carry_rating` / `carry_eventName`）。
相手のデッキ・勝敗・先後・初手・メモは従来どおり初期化する。

### 4. レート欄が英字入力に自動で切り替わる

レート欄にカーソルを入れると、入力ソースが英字（Roman）へ切り替わる。
SwiftUIの`TextField`では入力ソースを指定できないため、この欄だけ`NSTextField`
（`allowedInputSourceLocales = [NSAllRomanInputSourcesLocaleIdentifier]`）を`NSViewRepresentable`で包んでいる。

## 変えていないもの

日時スタンプの取り方（v1.20の修正）、記録される項目、戦績一覧、相性表、日別・月別集計、デッキ管理、
自動バックアップ（Mac内＋iCloud）、JSON/CSV入出力、SQLiteのスキーマ。データベースはそのまま引き継げる。

## ロールバック

`PokecaRecords_v1.20.app` は残してある。問題が出たらそちらを起動すればよい。

## 注意

バンドルIDが `com.local.pokecarecords.v121` に変わるため、v1.20で「左端に固定」したデッキの並びは引き継がれない
（v1.19→v1.20のときと同じ）。固定し直せば元に戻る。
