# ポケカ戦績 v1.18

v1.17の機能を保ったまま、複数のMacでデータを守り、受け渡せる自動バックアップを追加した。

## 自動バックアップ

- 戦績とデッキの保存・編集・削除のたびにJSONを作る。
- Mac内の `~/Library/Application Support/PokecaRecordsSwiftUI/Backups/<Mac名>/` へ必ず保存する。
- iCloud Driveが有効なら、`iCloud Drive/ポケカ戦績バックアップ/<Mac名>/` にも保存する。
- `pokeca_records_latest.json` と日付付きJSONを作り、日付付きは各Macで30件保持する。
- Macごとにフォルダを分けるので、別のMacが作ったバックアップを上書きしない。
- バックアップ画面から、保存先を開く、今すぐ保存する、JSONを選んで復元する、の3操作ができる。

## 復元の安全対策

- 復元前に現在のデータを自動バックアップする。
- JSON全体を読み取れたことを確認してからSQLiteを更新する。
- SQLiteの更新はトランザクション内で行い、失敗時は元のデータへ戻す。
- v1.17のJSON読み込みで、ID付きデッキが新規挿入されず画像・代表カード情報が落ちる可能性があった点も修正した。

## 注意

- SQLiteファイルそのものはiCloudへ置かない。同時書き込みによる破損を避けるため。
- これは自動バックアップと手動復元であり、複数端末の同時編集を自動統合する機能ではない。
