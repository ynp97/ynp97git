# ポケカ戦績 v1.19

v1.18の画面と自動バックアップを保ち、PTCGLのレート欄を追加した。

## 変更点

- 戦績入力の「相手のデッキ」の直後に「レート」欄を追加。
- その後の並びを「勝敗 → 先/後」に変更。
- 戦績一覧も「相手のデッキ → レート → 勝敗 → 先/後」の順に変更。
- 編集、複製、日別表示、検索、JSONバックアップ、CSV書き出しにレートを反映。
- SQLiteの旧データベースは起動時に自動移行し、既存197件のレートは空欄のまま保持する。
- v1.18以前のJSONは、レートが無くてもそのまま復元できる。

その他の画面構成・集計・デッキ管理・バックアップ方式は変更していない。

## 初回起動

macOSから「iCloud Drive」へのアクセス確認が出た場合は「許可」を選ぶ。許可後、バックアップ画面の「今すぐバックアップ」でMac内とiCloudの両方へ保存される。
