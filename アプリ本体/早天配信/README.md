# 早天配信

毎朝「早天配信.app」を開くとOBSが開きます。OBS右側の「聖書操作」で操作します。今日の予定を初期表示し、別の日を扱う場合は日付を選んで「表示」を押します。別のブラウザウインドウは開きません。

このMacでは標準Terminal経由で起動するため、起動時にTerminalの完了ウインドウも開きます。完了後は閉じて構いません。表示サーバーは独立して動きます。

- 「箇所名」：日付と聖書箇所。
- 「本文」：本文を一節ずつ表示。長い節は文字を省かず分割。
- 「前へ／次へ」または左右矢印：ページ送り。「節へ移動」で直接選択も可能。
- 「非表示」：聖書表示を消す。読みかけのページは保持。
- 配信開始はOBSで映像・音声を確認してから行います。

## このMac

- 実配置：`~/Desktop/AI関係/早天配信/早天配信.app`
- 操作画面：<http://127.0.0.1:19797/>
- OBSシーン：`早天・日付で準備`（シーンコレクション：早天）
- OBS内の操作パネル：ドック「聖書操作」。URLは `http://127.0.0.1:19797/?dock=1`。プレビューを省いた小型版です。見えなくなったらOBSの「ドック」メニューから「聖書操作」を表示します。
- OBSブラウザソース：`http://127.0.0.1:19797/display?obs=1`、1920×1080。
- 元の「シーン」は残しています。変更前の設定は実配置の「設定控え」に保存。
- 切断が3秒続くと文字を消し、古い本文が残り続けることを防ぎます。

通常のブラウザ操作画面も予備として残っています。必要時だけURLを開くか `python3 launch.py --browser` を使います。配信中はOBSとZoomを並べ、OBSの操作パネルで聖書を送れます。

## 予定・本文

`st97`と同じVaultの `.agents/skills/st97/references/YYYY-MM.md` および `聖書（新改訳2017）/書名.md` を直接読みます。月間予定の追加は起動中でも反映します。未登録日は推測せずエラーを出します。2026年7〜9月が登録済みです。次月はst97の手順で公式月間一覧を追加してください。

9月一覧はツラノ公式から取得済みですが、一覧の記録では日本CGNTVとの照合が未実施です。歴代誌第一15:10の人数についてはst97に誤記の疑いの記録があり、その日の操作画面に注意を出します。原文を勝手に訂正しません。

## 別の端末へ

Python 3.9以上、OBS、ブラウザを使用します。アプリのフォルダとVaultを移し、`python3 server.py --vault "Vaultの場所"` で起動。OBSで上記URLのブラウザソースを追加します。表示画面はOS非依存ですが、Mac用.appとカメラ・音声設定は移行先に合わせる必要があります。別端末では未検証です。

## 開発・検証

Python標準ライブラリのみ。外部への本文送信なし、127.0.0.1のみで待ち受け。`python3 -m unittest discover -s tests -v`。

`install_mac.py`はこの利用者のMac用です。OBSを終了した状態でのみ、初回シーンを追加します。再実行時はアプリのファイルだけ更新します。稼働中のサーバーはファイル更新だけでは再読込されないため、`.runtime/server.pid` の対象プロセスを確認して再起動してください。

## 毎日の祈り（2026-09-25追加）
OBS下側の操作バーで「祈り」は見出し、「主の祈り」は文語全文（末尾アーメン。）を表示。「本文」で元の聖書ページへ戻る。日付未登録でも祈りは使える。文語本文確認元：https://www.minoo-church.com/worship/lordsprayer.html

## 説明用の聖句・文章
「追加・管理」を押すと編集画面が開きます。聖書箇所に「ヨハネ3:16-18」などを入力して「聖句を追加」。文章は下の見出し・本文欄から追加できます。「表示」で表示、↑↓で順番変更。OBSの節選択欄の「説明：…」からも切替可能。「本文」で今日のページに戻ります。日付別に自動保存されます。
